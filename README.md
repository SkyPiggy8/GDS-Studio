# GDS Studio

**v0.2：版图样本库与大文件提取。** 主窗口点击「样本库」或 Ctrl+L。支持 GDS/OAS 多层与 Cell 定义提取、连通结构、区域裁剪、尺寸 / 同形比对、来源保留、论文 PDF 页裁剪、修正版入库，以及逐层平铺图谱和训练数据导出。详见 [操作说明](docs/SAMPLE_LIBRARY.md)、[真实论文提取示例](docs/PAPER_SAMPLES.md)。原编辑器和可调结构继续保留。

大文件在独立后台进程处理；图库每页 80 个样本。实际验证过 207.5 MiB、340 万多边形、40 层的合成 GDS 索引及 ROI 提取。真实 foundry 文件、复杂全芯片语义切分仍需用实际数据验收。

轻量 Windows 桌面版图编辑器，用于参数化测试图形生成、论文截图轮廓提取和检测样本准备。界面参考版图编辑器与流程图工具的操作习惯，使用独立实现；没有复制 KLayout 或 draw.io 的界面源码。

## 开始使用

直接双击本目录的 **启动 GDS Studio.cmd**。当前电脑已配置独立运行环境，启动不需要联网。

如果使用打包版本，打开 `dist/GDS Studio/GDS Studio.exe`，整个目录需要一起保留。

首次启动展示一组可编辑样本；菜单 **文件 → 新建空白版图** 开始自己的工程。`examples/starter.gsproj` 是起始示例；`catalog.gsproj` 包含全部 41 类结构。

## 基本操作

1. 单击结构库形状，右侧修改待放置参数。
2. 双击形状或点击“在画布放置”，再在画布点击；可连续放置，Esc 退出。
3. 点击画布对象，右侧修改参数；拖动移动，框选多选。右下角方块按外接矩形缩放。非 0°/90° 旋转的对象使用等比例缩放，右侧 X/Y 缩放可分别调整本地轴。
4. “复制阵列”设置行列数量与 X/Y **原点间距**；原始对象算第一个单元。
5. 参数扫描可选两个不同参数，输入逗号分隔取值。整数数量参数必须使用整数。
6. 任意轮廓先“展开为多边形”，再用顶点工具拖动圆点，或在坐标表修改、插入、删除顶点。多层结构拆成同层对象；带孔轮廓拆成简单片段，以便编辑。
7. 保存工程保留可调参数，导出 GDS 给检测程序。GDS 本身不保存本软件的参数化语义，需保留工程或 manifest。

快捷键：`V` 选择、`R` 矩形、`P` 多边形、`B` 手绘、`E` 顶点、`M` 测量、`F` 适应全部；空格/中键拖动平移，滚轮缩放；`Ctrl+D` 复制、`Ctrl+C/V` 剪贴板、`Delete` 删除、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Ctrl+S` 保存、`Ctrl+I` 图片、`Ctrl+E` GDS 导出。逐点多边形 Enter / 双击 / 右键闭合。

## 截图转版图

1. 导入 PNG、JPEG、TIFF 或 BMP。
2. 选择“框选图形区域”，排除标题、箭头、文字、比例尺与图框。
3. 选择“点选两点标定”，点两个已知物理距离的位置，输入 nm 距离，点击“应用标定”。没有已知尺寸时，可显式选择“未标定草图”导入，临时按 1 nm/px，后续调整整体尺寸。
4. 调整阈值、深浅颜色、最小区域面积、轮廓简化；蓝色覆盖预览代表实际提取几何。任选正交、45° 或原始方向。
5. 点击“导入到画布”，继续移动、缩放、展开或修改顶点。

这是几何轮廓提取，适合清楚的高对比版图示意。没有自动理解论文语义、分辨同色标注和图形、恢复被遮挡结构或推断真实尺寸的模型。SEM 纹理、压缩模糊、重叠彩色层可能需要裁剪和手工修整。算法使用像素中心轮廓，边缘约有像素尺度不确定性；标定记录不等于实物量测准确度。图片最多 3600 万像素，轮廓最多 10000 个。方向规整失败的轮廓会明确计数，不静默当成成功。

## 尺寸、工艺和检测

**显示和内部坐标统一为 nm。GDS user unit = 1e-9 m，precision = 1e-10 m。** 网格可从 0.1 nm 起调整；GDS 坐标量化到 0.1 nm。坐标范围约为 ±214 mm。导入 μm 单位 GDS 时自动转换为 nm。

库中的 12 nm 等默认数值是便于操作的研究测试值，**不是特定晶圆厂的 3 nm PDK**。3 nm 节点不表示所有线宽为 3 nm。TSMC N3 与 Samsung GAA 结构和工艺不同。库里覆盖公开文献中的几何类型，还包括非正交与缺陷测试图形，不能称为覆盖所有商业节点规则。工艺相关提示是简短的机制摘要和结构用途推断，软件未计算曝光、OPC、抗蚀剂、蚀刻或 CMP 物理结果。完整尺寸/层映射/工艺规则需由实际检测流程提供。

GDS 导出包括隐藏图层；显示/锁定属于编辑状态。Contact 等对象表示该层上的**前景区域**，其正/负掩膜含义由使用方决定；矩形环和图像孔洞则是实际空洞，使用 GDS 接缝/分割表示。Via、Cut、Active 辅助层默认使用主 Layer+1，Datatype 相同，可展开后重新映射。

`.manifest.json` 记录 Cell 对应形状 ID、名称、参数、扫描值、图片标定和来源。检测程序可按 Cell 或参数挑选样本。`.gsproj` 保留完整编辑状态。

## 源码与后续开发

Python 负责界面与调度，Qt 与 GDSTK 的 C++ 实现负责交互和几何底层。结构生成、文档、文件和图片提取与 UI 分离。参见 [架构说明](docs/ARCHITECTURE.md)、[交接说明](docs/HANDOFF.md) 和 [调研记录](docs/RESEARCH.md)。
