# 7 nm OPC 调研与实验功能

查阅日期：2026-10-21。

## 找到的公开资料

| 资料 | 可用于什么 | 不能据此得出的结论 |
|---|---|---|
| [ASU / ARM ASAP7 官网](https://asap.asu.edu/) | 研究用预测 PDK、规则与模型的来源 | 官网明确为学术研究用途，结果不可直接制造 |
| [ASAP7 官方发布仓库](https://github.com/The-OpenROAD-Project/asap7) 与其 [设计规则手册](https://github.com/The-OpenROAD-Project/asap7_pdk_r1p7/blob/main/docs/asap7_drm_201207a.pdf) | 按层检查绘制尺寸、间距和图层映射；手册链接已核实 | DRC 不是 OPC 修正规则；本次未把 PDF 数值转录到软件 |
| [Clark 等，ASAP7，2016](https://doi.org/10.1016/j.mejo.2016.04.006) | 说明预测工艺、关键层 EUV 假设与其他层多重图形化假设 | 不能把同一偏置用到所有层；节点名称不等于每层 CD |
| [OpenILT](https://github.com/OpenOPC/OpenILT) | 可供后续集成的光刻仿真、优化与评估框架 | 开源算法并不自带所用晶圆厂的量产标定模型 |
| [Zheng 等，Model-based OPC Extension in OpenILT，2024](https://www.cse.cuhk.edu.hk/~byu/papers/C209-ISEDA2024-ModelOPC.pdf) | 分段、成像仿真、边缘移动，以及 EPE / PVBand 等评估方法 | 论文并未提供可直接应用于任意 7 nm 工艺的通用尺寸查表 |

因此，本次没有找到可验证、可直接用于你的工艺的量产 7 nm OPC 规则集。
公开 PDK 可帮助收集研究版图、核实尺寸；校正量仍须由具体层、掩模极性、
光源与 NA、焦距 / 剂量窗口、掩模与光刻胶模型、实测数据共同决定。
这是根据上述资料作出的工程判断，不是对所有晶圆厂公开资料的穷尽证明。

## 软件中已实现

选择图案 →「图形 → 实验性 OPC 预览」，或右侧同名按钮。
蓝线是原图，橙色是校正后掩模几何；此处不显示晶圆预测轮廓。
预览不修改文档，通过后点击应用，替换所选对象，支持撤销。
按实际图层 / datatype 分组处理，辅助层保留映射；参数、原对象 ID、检查结果随工程和导出清单保存。

| 参数 | 初始值 | 实际行为 |
|---|---:|---|
| 边缘偏置 | +1 nm | 对多边形外扩，负值为内缩 |
| 线端延伸 | 3 nm | 仅对长宽比至少 2 的正交实心矩形两端加帽 |
| 线端横向扩张 | 2 nm | 上述线端帽横向扩张 |
| serif 半宽 | 2 nm | 正交轮廓外凸角添加方形角部补偿 |
| 同层间距下限 | 10 nm | 对校正后图形及未选择的同层图形进行间距检查 |

这些数值全部是本软件的演示初值，不来自 ASAP7 OPC deck，也不是推荐量产参数。
非正交轮廓只执行偏置，不添加角部或线端结构。暂未生成 SRAF，
因为没有成像模型就无法判断辅助图形是否不印出。

检查在 0.1 nm 量化后进行：连通分量或孔洞数量改变、图形消失、同层间距不足、
与未选图案相交时禁止应用。已重叠的输入按同层并集处理。
这只是几何防护，并非完整 MRC / DRC，也不保证拓扑数量不变时不存在局部缺陷。
一次最多 256 个轮廓、20000 个顶点，较大版图请先分批选择。

## 后续可升级方向

首先确定目标层与工艺，把 30–500 nm CD、pitch、间距、线端 / 拐角等图案组成标定集。
接入实测或已标定的光学 / 光刻胶模型后，再用分段边缘移动或 ILT 优化，
比较未校正与校正后的 EPE、CD 误差、工艺窗口和掩模规则。
当前程序没有仿真曝光结果，不能宣称 OPC 已改善成像质量。
