# 版图样本库操作

从主窗口「样本库」或 Ctrl+L 打开。首次使用自动收集内置形状和 examples 中的已有工程；数据库在当前运行目录的 userdata/library.sqlite。

## 收集大版图

1. 「大版图提取 → 添加 GDS / OAS 文件」。索引在独立进程运行，保留原始 Cell / AREF。
2. 选择多个 Cell 和 Layer/Datatype，选择提取单位。
3. 默认只取 Cell 定义本身的图形；需要实际放置后的区域，勾选「包含子 Cell 与阵列实例」。
4. 可填写左、下、右、上 ROI 坐标，单位 nm，坐标相对于每个所选 Cell。
5. 提取入库。数量超过上限会撤回整批，避免把不完整连通图形当成完整样本。

| 单位 | 用途 |
|---|---|
| 单多边形 / 路径 | 收集 T、L、拐角等独立轮廓；路径按其线宽变成面积 |
| 同层连通结构 | 合并同层接触或重叠轮廓，保留孔洞 |
| 指定区域 | 裁剪区域内所有图形，每层作为一个样本，适合 line-space、tip-to-tip 等多图形关系 |
| Cell 结构 | 每个 Cell 每层一个样本；保留图形之间的相对位置 |

文字不参与轮廓匹配。每个 Cell/层最多附带 200 条独立 Cell 定义中的文字备注，坐标注明为该 Cell 的局部坐标。备注不展开阵列，也不承诺与 ROI 精确对应；需要真实位置标签时后续可增加独立文本索引。

一个 GDS 的同形重复只保存一份几何，但每个来源、Cell、图层、提取方式和 ROI 都保留在 occurrences。图库按层排序，每页 80 个缩略图，避免把整个大文件放进编辑器。

## 比对与修正

选择样本，点击「在整个样本库中查找重复 / 相似」。新图片或画布结构入库后自动显示比对结果。

- 尺寸一致：忽略位置，几何保留 nm 尺寸和方向，量化到 0.1 nm。
- 等尺寸旋转 / 镜像：同时允许 90°、180°、270° 和镜像，不缩放。
- 同形：在上述基础上忽略整体等比例缩放，使用 1e-5 相对坐标量化。非等比拉伸不视为同形。
- 相似候选：最多从 80 个拓扑与填充率接近的候选中计算向量 IoU，显示前 20 个结果。不是全库近似召回率保证，也不用于自动删除。

跨图层可比对，结果显示 Layer/Datatype；入库去重按层和标定状态分开。未标定图片只参与同形匹配，不能据此认定实际线宽一致。

「送入画布修正」可以移动、缩放、顶点编辑。修改后选中对象，再点「收集当前选中 / 画布」保存修正版，保留原样本来源。标签和“人工审核”状态由用户填写，不自动宣称轮廓正确。

## 论文图片与 PDF

「导入图片 / 论文 PDF」可选择 PDF 页码和 DPI，随后使用同一个裁剪、阈值、两点标定和轮廓预览窗口。选择完整结构或独立轮廓入库。颜色图、标注、遮挡和 SEM 纹理仍需要裁剪或人工修正；截图不能恢复看不到的原始版图。

没有已知尺寸时显式按未标定草图导入。论文页、DPI、裁剪像素区域、标定信息均进入来源记录。默认不猜测“3 nm 节点”的尺寸规则。

## 导出

「导出数据集与分层图谱」选择父文件夹和新的目录名，导出整个样本库：

- masks/：256×256 二值 PNG，白色 255 为图形，黑色 0 为背景，孔洞保留。
- gds/：每个样本一个 GDS，附带回读验证后的 manifest。
- atlas/：每层每页最多 64 个平铺样本的 PNG 与 GDS。PNG 各缩略图独立缩放便于浏览，GDS 保留样本原尺寸；placement.json 记录平移和标定状态。
- manifest.json / index.csv：尺寸、图层、来源、标定、指纹、标签、审核状态和每张图的 nm_per_pixel。

未标定样本的 nm_per_pixel 为 null，GDS 坐标是临时尺寸。导出不会自动制造缺陷类别或监督标签。

训练 / 验证划分默认 unassigned。同形样本和共享源文件样本合并为 leakage_group，应把整组放在同一集合，避免来源或相同结构泄漏。来源混杂时整库可能连成一个大组，需要补充独立来源后再划分。

## 容量边界

KLayout 数据库仍会把输入文件加载到工作进程内存，不是磁盘流式解析器。独立进程能避免解析阻塞 UI，并在任务完成后释放数据库。首次索引和提取分别读取文件；取消发生在原生解析时会终止工作进程。SQLite 的未提交事务撤回，已经完成并提交的任务不撤回。

默认最多遍历 20000 个几何、产生 10000 个样本。可以提高上限，但非常复杂的单一样本（超过 20000 个多边形或 200000 顶点）应缩小区域；全芯片自动语义切分仍需增加规则或模型。
