# 精确版图编辑

## 整体移动

选择一个或多个图案，在右侧输入「左上角 X / Y」，点击「移动到坐标」。
基准是所有所选图案在世界坐标中的总包围盒左上角（最小 X、最大 Y），
包括参数结构的辅助层；旋转、镜像、缩放后仍使用同一定义。
多选时整个组合平移，保持内部相对位置。坐标为 nm，Y 轴向上。

按 G 进入移动工具，再点击画布目标位置，即将左上角放到该位置。
未选择对象时，第一次点击选择，第二次点击放置。画布显示左上角十字。
普通选择拖动也按同一基准吸附网格。所有移动均支持 Ctrl+Z / Ctrl+Shift+Z。
任意关联图层锁定时，整个对象禁止移动。

## 尺寸与吸附

上方和左侧标尺跟随平移、缩放，原点与版图坐标一致。勾选「几何吸附」时，
绘制、测量及顶点编辑优先吸附 9 屏幕像素内的端点，其次吸附边。
橙色高亮表示当前吸附目标；没有几何目标时使用文档网格。

按 D 进入尺寸工具：依次点两个顶点、两条平行边，或点与边。
单边长度：点击边的中部，再按 Enter。端点优先，选边请避开端点。
点间尺寸可选实际距离、水平距离、竖直距离；边间尺寸测量所在直线的垂直间距，
包括延长线上的投影，不是有限线段之间的最短距离。

第一项固定，修改尺寸移动第二项。不同对象默认整体平移第二个对象；
同对象内修改第二个顶点或整条边。正交模式沿相连竖直 / 水平边传播坐标，
使矩形改 CD 后仍为矩形。任意方向模式只移动被选中的顶点或边。
普通单层参数图形在顶点 / 边驱动编辑时自动展开；多图层结构需先手动展开。
锁定层可作测量基准，禁止作为被修改对象。非法、自交修改会回滚。

双击画布尺寸可重新输入数值或删除标注。「仅保留测量标注」不改变几何。
标注随 `.gsproj` 保存并随几何重算，GDS 仅导出几何。删除引用对象、改变顶点数量
后失效的标注会隐藏，应重新标注。支持撤销 / 重做。

这是直接尺寸驱动编辑，并非 SolidWorks 的完整约束求解器：多个历史标注是关联测量，
不会作为永久方程锁住模型；编辑其他尺寸后，已有标注会反映当前实际值。
